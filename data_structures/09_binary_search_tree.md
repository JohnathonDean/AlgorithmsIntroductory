# 二叉搜索树


## 概述

二叉搜索树是在普通二叉树基础上的进一步结构化结果。前一章中，二叉树已经提供了层次结构和递归处理方式；这一章进一步加入了关键的大小关系约束。

参考书在这里真正要说明的是：

- 一旦在二叉树上加入有序性
- 查找、插入和删除就可以利用这种有序性大幅减少搜索范围

因此，二叉搜索树是从“树结构”过渡到“搜索结构”的关键一章。


## 搜索树的数据结构

### 1. 二叉搜索树的概念定义

二叉搜索树通常满足下面的性质：

- 对任一节点，其左子树中的元素都小于该节点
- 其右子树中的元素都大于该节点
- 左右子树本身也分别是二叉搜索树

这说明二叉搜索树最核心的内容不是“它是一棵二叉树”，而是：

- 它是一棵具有递归有序性的二叉树

### 2. 二叉搜索树包含的基本操作

围绕这种有序性，二叉搜索树中最重要的操作通常包括：

- 查找某个元素
- 插入一个新元素
- 删除某个元素
- 找到最大值或最小值
- 按中序遍历输出有序序列

这些操作都比普通二叉树更有针对性，因为它们不再需要无差别遍历所有节点。

### 3. 为什么 BST 能加速查找

普通二叉树在查找时，往往没有足够信息判断下一步该往哪里走；
而二叉搜索树由于满足左小右大的关系，因此在每一步比较之后，都可以直接排除掉半边子树。

也就是说，BST 的优势来自：

- 每次比较都能缩小搜索范围

这正是它成为搜索结构的根本原因。

### 4. BST 抽象上的关键认识

学习二叉搜索树时，最重要的不是背性质本身，而是理解：

- 这棵树之所以高效，是因为有序性被维护在结构内部

如果这层性质被破坏，BST 就退化成普通二叉树；如果树高又变得很大，查找效率也会明显下降。

## 二叉搜索树的描述

## 1. 查找

二叉搜索树的查找过程非常直接：

- 如果目标等于当前节点，查找成功
- 如果目标小于当前节点，去左子树查找
- 如果目标大于当前节点，去右子树查找

这说明 BST 查找过程的本质不是“遍历”，而是：

- 沿着有序性指引的一条路径逐步逼近目标

### 2. 插入

插入过程和查找非常接近。

基本思想是：

- 先按照查找规则向下走
- 直到遇到空位置
- 再把新节点接到那个位置上

因此，插入操作最重要的前提是：

- 插入后仍然保持二叉搜索树的有序性

这也是为什么新元素不能随意放在任意节点旁边，而必须沿比较路径落到合适位置。

### 3. 删除

删除是 BST 中最需要分类讨论的操作。

通常分成三种情况：

- 删除叶节点
- 删除只有一个孩子的节点
- 删除有两个孩子的节点

前两种相对直接；
第三种最关键，因为它既要删掉目标节点，又不能破坏整棵树的有序性。

因此，删除有两个孩子的节点时，通常会：

- 用左子树最大节点或右子树最小节点替代它

这种做法的目的，本质上是：

- 找一个仍然能保持有序性的替代者

### 4. 中序遍历与 BST 的关系

二叉搜索树有一个非常重要的性质：

- 对 BST 做中序遍历，会得到一个有序序列

这一点非常值得记住，因为它把：

- 树结构
- 顺序序列

直接联系了起来。

也正因为如此，BST 常常被看作一种既保留树形结构、又保留有序关系的搜索结构。


## 总结

这一章的核心任务，是理解二叉树在加入有序性之后，如何变成一种高效的搜索结构。

可以把主要认识归纳为：

- 二叉搜索树是一种满足左小右大性质的二叉树
- 查找、插入和删除都依赖这种递归有序性
- 删除操作之所以复杂，是因为必须在修改结构的同时保持有序性
- BST 的中序遍历结果天然有序
- BST 的效率不仅取决于有序性，也取决于树高是否合理

下一章学习平衡搜索树时，重点就是继续解决 BST 在极端情况下可能退化的问题。
